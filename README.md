## 📖 Deskripsi

Website portofolio interaktif yang menampilkan profil profesional, proyek-proyek unggulan, keahlian teknis, sertifikat, dan informasi kontak. Dibangun dengan React dan Vite untuk performa optimal dengan pengalaman pengguna yang modern dan responsif.

## ✨ Fitur Utama

- **Hero Section** - Tampilan pembuka yang menarik dengan efek visual
- **About** - Informasi profil dan latar belakang
- **Skills** - Daftar keahlian dan teknologi yang dikuasai
- **Projects** - Showcase proyek-proyek unggulan dengan detail
- **Certificates** - Galeri sertifikat dan pencapaian
- **Contact** - Form dan informasi kontak
- **Language Switcher** - Dukungan multi-bahasa (Indonesia & English)
- **3D/Tilt Effects** - Efek interaktif pada kartu untuk pengalaman yang lebih menarik

## 📦 Menjalankan Proyek Secara Lokal

### Prasyarat
Pastikan Anda telah menginstal Node.js dan npm di sistem Anda.

### Instalasi

1. Clone repository ini:
```bash
git clone https://github.com/Wahyudayat1/React-Portfolio.git
cd React-Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Jalankan development server:
```bash
npm run dev
```

4. Buka browser dan akses `http://localhost:5173`

### Build untuk Production

```bash
npm run build
```

File hasil build akan tersimpan di folder `dist/`.

### Preview Build Production

```bash
npm run preview
```
